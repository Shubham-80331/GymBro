# GymBro 🏋️

GymBro is an Android fitness application designed to help users organize and track their workout routines in one place.

## Features

- 🏋️ Workout and exercise tracking
- 📋 Organized exercise routines
- 📊 Track workout progress
- 🎯 Simple and focused fitness interface
- 📱 Native Android experience

## Tech Stack

- **Language:** Kotlin
- **Platform:** Android
- **Build System:** Gradle
- **UI:** Android Views / XML
- **IDE:** Android Studio
